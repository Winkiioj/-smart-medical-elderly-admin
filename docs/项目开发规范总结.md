## 二、后端分层架构（SpringBoot + MyBatisPlus）

### 2.1 包的命名规则

```
com.hwadee.<项目名>.<分层>
com.hwadee.springboot.entity    → 实体类
com.hwadee.springboot.mapper    → Mapper 接口
com.hwadee.springboot.service   → Service 接口
com.hwadee.springboot.service.impl → Service 实现
com.hwadee.springboot.controller → Controller
com.hwadee.springboot.common.config → 配置类
com.hwadee.springboot.common.exception → 异常处理
com.hwadee.springboot.common.result → 统一返回结果
com.hwadee.springboot.common.enums → 枚举常量
com.hwadee.springboot.aop → 切面
```

### 2.2 实体类（Entity）写法

实体类使用 **Lombok** 简化代码，用 **MyBatisPlus 注解** 映射数据库表：

```java
@Data                           // Lombok：自动生成 getter/setter/toString/equals/hashCode
@TableName("user")              // MyBatisPlus：指定对应数据库表名
public class User {
    @TableId(type = IdType.AUTO) // 主键，自增策略
    private Long userId;

    private String name;
    private Integer age;
    private String email;

    @TableLogic                  // 逻辑删除标记（0=未删, 1=已删）
    private Integer isDelete;
}
```

**关键注解速查：**

| 注解 | 作用 | 常用属性 |
|------|------|----------|
| `@TableName` | 指定映射的表名 | `value="表名"` |
| `@TableId` | 标记主键字段 | `type=IdType.AUTO`（自增）、`ASSIGN_ID`（雪花算法） |
| `@TableField` | 标记非主键字段 | `exist=false`（非表字段）、`fill=FieldFill.INSERT`（自动填充） |
| `@TableLogic` | 逻辑删除 | `value="0"`（未删）, `delval="1"`（已删） |

### 2.3 Mapper 层（DAO）写法

```java
// 接口继承 BaseMapper<实体类>，自动获得 CRUD 方法
@Mapper
public interface UserMapper extends BaseMapper<User> {
    // 自定义方法：分页查询
    IPage<User> selectPageVo(IPage<User> page, @Param("age") int age);
}
```

Mapper XML（仅在自定义 SQL 时需要，放在 `resources/mapper/` 下）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.hwadee.springboot.mapper.UserMapper">
    <select id="selectPageVo" resultType="com.hwadee.springboot.entity.User">
        select * from user where age = #{age} and is_delete = 0
    </select>
</mapper>
```

**不要忘记在启动类或配置类中扫描 Mapper：**

```java
@MapperScan("com.hwadee.springboot.mapper")
```

### 2.4 Service 层写法

接口：
```java
public interface UserService extends IService<User> {
    IPage<User> myPageSelect(IPage<User> page, int age);
}
```

实现类（关键：`@Service` + `@Transactional` + 继承 `ServiceImpl<Mapper, Entity>`）：
```java
@Service
@Transactional  // 所有 Service 实现类都需要开启事务支持
public class UserServiceImpl extends ServiceImpl<UserMapper, User>
        implements UserService {

    @Override
    public IPage<User> myPageSelect(IPage<User> page, int age) {
        return this.baseMapper.selectPageVo(page, age);
    }
}
```

**Service 继承链：**

```
UserService (自定义接口)
  ↑ extends IService<User>

UserServiceImpl (自定义实现)
  ↑ extends ServiceImpl<UserMapper, User>  ← MyBatisPlus 提供，自动拥有 CRUD 方法
  ↑ implements UserService
```

### 2.5 Controller 层写法

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @Autowired
    private UserService userService;

    // 分页查询
    @GetMapping("/page")
    public CommonResult page(@RequestParam int pageNo, @RequestParam int pageSize) {
        Page<User> page = new Page<>(pageNo, pageSize);
        LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
        wrapper.orderByAsc(User::getAge);
        userService.page(page, wrapper);
        return CommonResult.success(page);
    }

    // 根据 ID 查询
    @GetMapping("/getById/{id}")
    public CommonResult getById(@PathVariable Long id) {
        User user = userService.getById(id);
        return CommonResult.success(user);
    }

    // 新增
    @PostMapping("/add")
    public CommonResult add(@RequestBody User user) {
        userService.save(user);
        return CommonResult.success(null);
    }

    // 修改
    @PutMapping("/update")
    public CommonResult update(@RequestBody User user) {
        userService.updateById(user);
        return CommonResult.success(null);
    }

    // 删除
    @DeleteMapping("/delete/{id}")
    public CommonResult delete(@PathVariable Long id) {
        userService.removeById(id);
        return CommonResult.success(null);
    }
}
```

## 三、一条完整业务线的执行流程

以"查询老人档案列表"为例，展示从前端到数据库的完整调用链：

```
前端 Vue 组件
  ↓ 调用 api/getData.js 封装的方法
  ↓ axios 发送 GET/POST 请求 → request.js 拦截器自动加 Token
  ↓ 跨域 → WebConfig.java 的 CorsFilter 放行
  ↓ AOP 切面 → @Around 检查 Token 是否有效（Redis）
  ↓ Controller 方法接收请求参数
  ↓ Controller 调用 Service 方法
  ↓ Service 调用 Mapper 方法
  ↓ MyBatisPlus 生成 SQL 或执行 XML 中的 SQL
  ↓ MySQL 数据库
  ↓ 返回结果逐层向上
  ↓ Controller 包装为 CommonResult 返回 JSON
  ↓ axios 响应拦截器解析 code 码
  ↓ Vue 组件使用响应式数据渲染页面
```

## 四、公共能力封装（common 包）

### 4.1 统一返回结果

```java
public class CommonResult<T> {
    private int code;      // 业务状态码（200=成功）
    private String msg;    // 提示信息
    private T data;        // 返回数据

    public static <T> CommonResult<T> success(T data) {
        return new CommonResult<>(200, "操作成功", data);
    }

    public static <T> CommonResult<T> error(GlobalErrorCodeConstants error) {
        return new CommonResult<>(error.getCode(), error.getMsg(), null);
    }
}
```

**所有 Controller 方法都返回 `CommonResult`**，前端统一从 `response.data.code` 判断成功或失败。

### 4.4 跨域配置

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Bean
    public FilterRegistrationBean<CorsFilter> corsFilterBean() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowCredentials(true);
        config.addAllowedOriginPattern("*");   // 允许所有来源
        config.addAllowedHeader("*");          // 允许所有请求头
        config.addAllowedMethod("*");          // 允许所有请求方法(GET/POST/PUT/DELETE)

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);

        FilterRegistrationBean<CorsFilter> bean =
            new FilterRegistrationBean<>(new CorsFilter(source));
        bean.setOrder(99999);
        return bean;
    }
}
```

### 4.5 AOP 切面（Token 校验）

```java
@Component
@Aspect
public class AroundCut {

    @Autowired
    StringRedisTemplate redisTemplate;

    // 切入点：拦截指定包下所有 Controller 方法
    public static final String POINT_CUT =
        "execution(* com.hwadee.springboot.controller.*.*(..))";

    @Around(AroundCut.POINT_CUT)
    public CommonResult checkToken(ProceedingJoinPoint pjp) throws Throwable {
        // 1. 从请求头获取 Token
        String token = ((ServletRequestAttributes)
            RequestContextHolder.getRequestAttributes())
            .getRequest().getHeader("Token");

        // 2. 去 Redis 中验证 Token 是否有效
        String userInfo = redisTemplate.opsForValue().get("Token::" + token);
        if (StringUtils.isBlank(userInfo)) {
            return CommonResult.error(GlobalErrorCodeConstants.UNAUTHORIZED);
        }

        // 3. Token 有效，继续执行目标方法
        return (CommonResult) pjp.proceed();
    }
}
```

## 六、MyBatisPlus 条件构造器速查

```java
// QueryWrapper：构建查询条件（字段名用字符串）
QueryWrapper<User> qw = new QueryWrapper<>();
qw.like("email", "test").eq("age", 21).orderByAsc("user_id");
List<User> users = userMapper.selectList(qw);

// LambdaQueryWrapper：构建查询条件（字段名用 Lambda，避免硬编码）
LambdaQueryWrapper<User> lqw = new LambdaQueryWrapper<>();
lqw.like(User::getEmail, "test").ge(User::getAge, 18);
List<User> users = userMapper.selectList(lqw);

// UpdateWrapper：构建更新条件
UpdateWrapper<User> uw = new UpdateWrapper<>();
uw.eq("user_id", 2).set("name", "新名字").set("email", "new@qq.com");
userMapper.update(null, uw);

// LambdaUpdateWrapper
LambdaUpdateWrapper<User> luw = new LambdaUpdateWrapper<>();
luw.eq(User::getUserId, 1)
   .set(User::getName, "小张")
   .set(User::getEmail, "888@qq.com");
userMapper.update(null, luw);

// 分页查询
Page<User> page = new Page<>(pageNo, pageSize);
userService.page(page, lqw);
System.out.println(page.getRecords()); // 当前页数据
```

### 7.3 axios 请求封装（request.js）

```javascript
import axios from 'axios';
import { ElMessage } from 'element-plus';
import { getStorage } from "@/utils/localStorage.js";
import Router from '@/router';

const service = axios.create({
    baseURL: "http://localhost:8080",  // 后端地址
    timeout: 10000,
    crossDomain: true
})

// 请求拦截器：自动在请求头加 Token
service.interceptors.request.use(
    config => {
        config.headers['Token'] = getStorage('Token')
        return config
    },
    error => Promise.reject(error)
)

// 响应拦截器：统一处理返回结果
service.interceptors.response.use(
    response => {
        if (response.data) {
            if (response.data.code == 200) {
                return response.data          // 成功，返回数据
            } else if (response.data.code == 401) {
                ElMessage.error(response.data.msg)
                Router.push({ path: "/" })    // Token 失效，跳转登录页
                return false
            } else {
                ElMessage.error(response.data.msg)
            }
        }
        return -1;
    },
    error => Promise.reject(error)
)

export default service
```

## 八、开发流程总结

按讲义的标准开发流程，每完成一个功能模块的步骤：

```
1. 建表（MySQL）
   CREATE TABLE ... 对应业务表

2. 创建实体类（entity/）
   @Data + @TableName + @TableId + @TableLogic

3. 创建 Mapper 接口（mapper/）
   extends BaseMapper<Entity>
   如有复杂查询 → 同时在 resources/mapper/ 下编写 XML

4. 创建 Service 接口 + 实现类（service/ + service/impl/）
   extends IService<Entity> + extends ServiceImpl<Mapper, Entity>
   @Service + @Transactional

5. 创建 Controller（controller/）
   @RestController + @RequestMapping
   注入 Service → 编写 CRUD 接口 → 返回 CommonResult

6. 前端封装 API 调用（api/getData.js）
   使用 request.js 定义请求方法

7. 前端编写 Vue 页面（views/）
   使用 <script setup> + ElementPlus 组件
   调用 API 获取数据 → 响应式渲染
```

## 九、核心设计模式与约定

| 模式 | 说明 |
|------|------|
| **分层架构** | Controller → Service → Mapper → Entity，严格单向依赖 |
| **统一返回格式** | 所有 Controller 返回 `CommonResult`，前端统一解析 `code/msg/data` |
| **全局异常拦截** | `@RestControllerAdvice` 兜底所有未捕获异常，返回统一错误 JSON |
| **AOP 切面** | Token 校验、日志记录等横切关注点通过 `@Aspect` + `@Around` 实现 |
| **继承复用** | Mapper 继承 `BaseMapper` 获得 CRUD；Service 继承 `ServiceImpl` 获得 CRUD |
| **Lambda 防硬编码** | 条件构造器使用 `LambdaQueryWrapper` 替代字符串字段名 |
| **axios 拦截器** | 请求拦截器自动注入 Token；响应拦截器统一处理业务状态码 |
| **逻辑删除** | 使用 `@TableLogic`，delete 操作变为 update is_delete=1 |
